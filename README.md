Provides Tree-sitter powered semantic syntax highlighting and language support for **Mantiq** (`.mq`) and **Nizam** (`.nz`).

## Features

- **Tree-sitter Semantic Highlighting**: Accurate grammar-aware highlighting for variables, types, functions, keywords, operators, and docstrings.
- **Dual Language Support**: Seamless editing for both Mantiq and Nizam source files.
- **Language Configurations**: Auto-closing brackets, line comments (`//`), and block comments (`/* ... */`).

## File Extensions

- `.mq` — Mantiq source files
- `.nz` — Nizam source files
